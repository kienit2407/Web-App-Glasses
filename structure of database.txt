    3. Roadmap đề xuất (theo feature, không theo layer)
    
Bước 1: Gắn FE user với BE — Product listing + detail

Thay mockProducts bằng API:

GET /products → filter/sort/search đúng cái UI bạn đã code.

GET /products/:productId → detail + variants + images.

Ở step này:

Chỉ cần trong DB có vài products/variants/images là đủ.

Bạn có thể:

Insert trực tiếp bằng Compass

Hoặc viết 1 file seed script tạo 10 cái kính fake.

➡️ Sau step này: khách xem sản phẩm thật từ DB được.

Bước 2: Auth + Profile + Address

FE:

Login / Register gọi:

POST /auth/signin

POST /auth/signup

Lưu accessToken vào Zustand.

/user/me hiển thị profile basic.

/address dùng:

GET /address

POST/PATCH/DELETE /address

BE:

Đảm bảo middleware protectUserRoute hoạt động chuẩn.

Địa chỉ sử dụng geo data từ DB (provinces/districts/wards).

➡️ Sau step này: khách đăng ký → đăng nhập → thêm địa chỉ nhận hàng được.

Bước 3: Cart flow

FE:

Nút “Add to cart” trên product detail gọi POST /cart/items.

Trang Cart:

GET /cart

PATCH /cart/items/:itemId để đổi quantity

DELETE /cart/items/:itemId để xóa.

BE:

Hoàn thiện cartService + cartController như mình và bạn đã bàn:

Upsert, gộp variant, snapshot price_at_add.

➡️ Sau step này: khách thêm/gỡ/sửa số lượng trong giỏ bằng data thật.

Bước 4: Checkout preview

FE:

Từ page Cart: chọn item → bấm “Thanh toán”.

Gửi POST /checkout/preview với:

cart_item_ids

address_id

coupon_code?

Hiển thị:

Danh sách sản phẩm đã chọn

Subtotal

Giảm giá từ coupon

Phí ship

Tổng thanh toán.

BE:

Dùng calculatePricingFromCartSelection (như mình gợi ý) → gọi coupons + shippingService.

➡️ Sau step này: khách thấy đúng số tiền phải trả trước khi đặt hàng, rất giống Shopee/Lazada.

Bước 5: Tạo order (transaction)

FE:

Từ màn checkout preview → bấm “Đặt hàng”.

Gửi POST /orders với payload giống preview (cùng set).

Nếu phương thức thanh toán = COD → hiển thị “Đặt hàng thành công”.

Nếu VNPAY/MOMO → redirect flow sau, có thể để tương lai.

BE:

Tạo orderService.createOrder dùng transaction như mình đã phân tích:

Tính lại tiền

Tạo order + order_items

Trừ stock

Xóa cart items đã chọn.

➡️ Sau step này: luồng mua hàng cơ bản hoàn chỉnh (chưa cần thanh toán online).

Bước 6: Order history + Order detail cho user

FE:

Trang “Đơn hàng của tôi”:

GET /orders?status=&page=&limit=

Trang chi tiết đơn hàng:

GET /orders/:id.

BE:

order.listMy, order.detailMy, order.cancelMy.

➡️ User xem lịch sử & hủy đơn pending được.

Bước 7: Lúc này mới quay qua admin

Khi user flow đã ổn, bạn quay lại làm admin UI theo mức độ cần thiết:

Admin products (quan trọng nhất):

CRUD brand, category, product, variant, image.

Admin orders:

Xem đơn và cập nhật trạng thái.

Admin coupons & promotions (nếu cần):

Tạo mã giảm giá, gán vào promotion.

Ở giai đoạn này, vì bạn đã có BE admin + model + route gần như đầy đủ, FE admin chỉ là “bọc UI shadcn quanh API”.
